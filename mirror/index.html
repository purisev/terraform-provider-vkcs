Terraform network mirror for the VKCS provider

This site serves provider metadata by the Terraform provider network mirror protocol. Archives are downloaded from the releases of purisev/terraform-provider-vkcs.

Setup

Add to ~/.terraformrc (Linux, macOS) or %APPDATA%\terraform.rc (Windows):

provider_installation {
  network_mirror {
    url     = "https://purisev.github.io/terraform-provider-vkcs/"
    include = ["vk-cs/vkcs", "purisev/vkcs"]
  }
  direct {
    exclude = ["vk-cs/vkcs", "purisev/vkcs"]
  }
}

Then reference the provider as usual:

terraform {
  required_providers {
    vkcs = {
      source  = "vk-cs/vkcs"
      version = "~> 0.18.1"
    }
  }
}

Run terraform init -upgrade to pick up a new version.

Available versions

  • registry.terraform.io/vk-cs/vkcs
  • registry.terraform.io/purisev/vkcs
